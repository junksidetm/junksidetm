- 🔭 **Currently Building:** High-performance offline personal finance ([`Wallet`](https://github.com/junksidetm/Wallet)) and multimedia chat visualizers ([`Wasm`](https://github.com/junksidetm/wasm)).
- 🧠 **Architectural Philosophy:** Single Source of Truth, zero runtime bloat, and complete user data sovereignty (zero cloud dependencies).

### 🔍 Engineering Principles & Architectural Mandates

<details>
  <summary><b>Click to expand: Core Software Principles & Standards</b></summary>
  <br />

  - **Surgical Precision:** Minimalistic, targeted refactors preserving verified structures and execution contexts.
  - **Offline-First Mandate:** Core business logic, analytics, and transaction computations derive locally without cloud latency or third-party telemetry leaks.
  - **Native Performance Standard:** Target 60–120 FPS continuous frame pacing via hardware-accelerated Compose Canvas and low-memory daemon profiles.
  - **Dynamic Ecosystem Synchronization:** Real-time auto-discovery of newly deployed repositories via GitHub REST APIs without requiring manual site rebuilds.

</details>

<details>
  <summary><b>Click to expand: Hardware & Development Environment</b></summary>
  <br />

  - **Primary OS:** Windows 11 (Tuned & Debloated via WinForge)
  - **IDEs:** Android Studio Ladybug/Meerkat, VS Code, JetBrains Fleet
  - **Terminals:** PowerShell 7+ with custom Starship prompt & GitHub CLI (`gh`)
